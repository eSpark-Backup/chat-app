# Chat App

This project was constructed for a chat-app coding challenge to test the react native development skills in expo for hybrid platform (iOS, Android, Web).

## Prerequisites

- [Node.js > 12](https://nodejs.org) and npm (Recommended: Use [nvm](https://github.com/nvm-sh/nvm))
- [yarn](https://yarnpkg.com/)
- [expo-cli](https://expo.dev/)

## Dependencies

- `@expo/webpack-config`
- `react-dom`
- `react-native-web`

## Usage

#### Run Project

git clone `https://github.com/eSpark-Consultants/chat-app.git` // clone the repo
- Go to your project's root folder and run `yarn`.
- E.g cd `chat-app` & `yarn`

- Run `npm start` or `yarn start` if using yarn, to start your application!
- Use the [Expo Go](https://expo.dev/client) app for viewing build in iOS/Android and press `w` to run on web

## Folder structure

This project follows a very simple project structure:

  - `assets`: Asset folder to store all images, vectors, etc.
  - `components`: Folder to store any common component that you use through your app (such as a generic button)
  - `utils`: Folder to store utility functions and globalState logic.
  - `App.js`: Main component that starts your whole app.
  - `index.js`: Entry point of your application as per React-Native standards.
